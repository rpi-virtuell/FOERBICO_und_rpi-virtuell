# Kind 30142 — AMB-Metadaten

**Zweck:** Strukturierte Bildungsmetadaten nach dem AMB-Schema ("Allgemeines
Metadatenprofil für Bildungsressourcen"). Macht den Post für OER-Suchmaschinen und
-Aggregatoren (z. B. OERSI) maschinenlesbar auffindbar: Lizenz, Autor\*innen, Fach,
Sprache, Materialtyp, Bildungsstufe.

**Wird nur erzeugt, wenn** `commonMetadata.type: LearningResource` im Frontmatter
gesetzt ist. Reine Blogposts ohne diesen Typ bekommen kein 30142-Event.

**Relay:** `wss://amb-relay.edufeed.org/`

**Baut aus:** `commonMetadata` im Frontmatter, siehe
[`events/amb.ts`](https://github.com/edufeed-org/mdparser/blob/main/sync/events/amb.ts)
im `mdparser`-Repo.

**Adressierbares Event:** derselbe `d`-Tag (Slug) wie das zugehörige 30023-Event —
kollidiert nicht, weil `kind` Teil der Adresse `kind:pubkey:d` ist.

## Feld-Mapping

| Frontmatter-Feld | Nostr-Tag | Bemerkung |
|---|---|---|
| `id` (letztes Pfadsegment) | `d` | Slug, identisch zum 30023-Event |
| `type` | `type` | Fallback `LearningResource` |
| `name` | `name` | |
| `description` | `description` | auch als `content` |
| `license` | `license:id` | |
| `creator[].givenName` + `familyName` | `creator:name` | ein Tag-Satz pro Creator |
| `creator[].type` | `creator:type` | |
| `creator[].id` | `creator:id` | |
| `creator[].affiliation.name` | `creator:affiliation:name` | |
| `creator[].affiliation.id` | `creator:affiliation:id` | |
| `inLanguage` | je `inLanguage` | alle Einträge (anders als bei 30023) |
| `about` | je `about:id` | |
| `learningResourceType` | je `learningResourceType:id` | |
| `educationalLevel` | je `educationalLevel:id` | |
| `datePublished` | `datePublished` | als Datumsstring, nicht als Timestamp |
| `image` | `image` | |
| `keywords` | je `t` | |
| — | `a` | Querverweis zurück auf das 30023-Event, Marker `content` |
