# Kind 1063 — Bild-Lizenznachweis

**Zweck:** Ein eigenständiges Event **pro Bild**, das dessen Lizenz, Quelle und Credit
bezeugt (NIP-94 File Metadata). Wird nicht aus `commonMetadata`, sondern aus dem
`# bilder`-Block im Frontmatter gebaut — dem Konventions-Block, in dem die Redaktion
Bildattribution pro Datei/URL pflegt.

**Relays:** `wss://relay-rpi.edufeed.org/` und `wss://relay.edufeed.org/`
(`LICENSE_RELAYS`) — getrennt von den Content-Relays für 30023/30142.

**Baut aus:** dem `# bilder`-Block + der tatsächlichen Bilddatei im Post-Ordner (für
Hash, MIME-Typ, Dateigröße), siehe
[`core/bilder.ts`](https://github.com/edufeed-org/mdparser/blob/main/sync/core/bilder.ts)
im `mdparser`-Repo, Funktion `nachweisEvent`.

Zum 1063-Event gehört immer auch ein Upload des Bild-Blobs selbst zu **Blossom**
(`https://blossom.edufeed.org`, BUD-01) — das Event bezeugt nur die Lizenz, die
Bilddaten liegen als Blob unter derselben Hash-URL.

## Feld-Mapping

| Quelle | Nostr-Tag | Bemerkung |
|---|---|---|
| Blossom-URL des Bildes | `url` | |
| SHA-256-Hash der Bilddatei | `x` | dasselbe Hash, das auch im `x`-Tag des 30023-Events steht |
| MIME-Typ (aus Dateiendung) | `m` | nur, wenn die Datei bekannt ist |
| Dateigröße in Bytes | `size` | nur, wenn die Datei bekannt ist |
| `title` (aus `# bilder`) | `title` | |
| `licenceUrl` | `license` | Pflicht — ohne `licenceUrl` wird kein Nachweis erzeugt |
| `author` | `credit` | |
| `alt` (Fallback: `title`) | `alt` | |
| `sourceUrl` | `source` | optional |
| `authorUrl` | `authorUrl` | optional, kein NIP-Standard |
| `modification` | `modification` | optional, kein NIP-Standard |
| `pubkey` | `p` | optional, z. B. für Fremdautor\*innen |
| `ai` (`generated` \| `modified`) | `ai` | optional, KI-Beteiligung nach edufeed-Wiki; ungültige Werte erzeugen keinen Tag |

Ein neuer Nachweis wird nur veröffentlicht, wenn sich seine Tags vom letzten
bekannten 1063-Event mit demselben Hash unterscheiden (`nachweisGleich`) — sonst
passiert nichts, um das Relay nicht mit identischen Events zu fluten.

## Beispiel (echtes, veröffentlichtes Event)
