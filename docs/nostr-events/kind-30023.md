# Kind 30023 — Article

**Zweck:** Der eigentliche Blogpost als "long-form content" (NIP-23). Trägt Titel,
Zusammenfassung, Cover-Bild und den vollständigen Markdown-Text. Wird für **jeden**
Post erzeugt, unabhängig vom `type`-Feld.

**Relay:** `wss://relay-rpi.edufeed.org/`

**Baut aus:** `commonMetadata` im Frontmatter, siehe
[`events/article.ts`](https://github.com/edufeed-org/mdparser/blob/main/sync/events/article.ts)
im `mdparser`-Repo.

**Adressierbares Event:** `kind:pubkey:d` — durch den `d`-Tag ersetzt eine neue
Version die alte auf dem Relay (Replaceable Event), statt sie zu duplizieren.

## Feld-Mapping

| Frontmatter-Feld | Nostr-Tag | Bemerkung |
|---|---|---|
| `id` (letztes Pfadsegment) | `d` | Slug, z. B. aus `https://oer.community/foo` → `foo` |
| `name` | `title` | |
| `description` | `summary` | mit Sprachcode als drittem Wert |
| `datePublished` | `published_at` | als Unix-Timestamp |
| `inLanguage[0]` | `inLanguage` | nur der erste Eintrag |
| `image` | `image` | Roh-URL aus dem Frontmatter |
| `image` (falls Hash im Pfad) | `x` | SHA-256-Hash, direkt nach `image` — markiert das Cover |
| Bilder im Markdown-Text (mit Hash-URL) | je ein `x` | dedupliziert, ohne das Cover doppelt zu zählen |
| `about` | je ein `about` | |
| `keywords` | je ein `t` | Hashtag-Tags |
| — | `a` (nur wenn `type: LearningResource`) | Querverweis auf das `30142`-Event, Marker `content` |
| Markdown-Fließtext | `content` | unverändert, keine Transformation |

Bilder ohne SHA-256-Hash im URL-Pfad (relative Pfade, fremde Hosts) bekommen **kein**
`x`-Tag — ein erratener Hash wäre schlimmer als keiner.
